Planters Club adalah penyelenggara dan logo utama: `logo-planters-club-horizontal-white.png` untuk header (berlatar `band`, sendirian, tanpa pelat); `logo-planters-club-horizontal.png` untuk footer dan gambar bagikan; `logo-planters-club.png` (tumpuk) bila ruang tinggi; `logo-planters-club-mark.png` (ikon saja) untuk favicon dan ruang sangat sempit. Danantara (`logo-danantara.png`) dan PTPN (`logo-ptpn-holding.png`) adalah logo induk: hanya di footer dan gambar bagikan, selalu sesudah Planters Club, dipisah garis, lebih kecil. Semua logo memakai warna asli; di atas `band`, taruh di pelat terang `band-ink`. Versi `-white` lain tidak dipakai. `logo-greenstride-white.png` adalah logotype acara, hanya di atas `band`. `logo-holding-only.png` untuk ruang sempit. Jangan mengubah warna atau proporsi.
